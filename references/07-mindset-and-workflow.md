# 07 如何用一年变成小红书博主：3 大能力 + 4 个思维 + 内容生产流程

---

## 一、3 大能力

### 1. 拆解力（爆款笔记五步拆解法）

**Step 1 记录基本信息**
| 模块 | 内容（示例） |
|---|---|
| 账号名称 | 瘦鬼的干货小铺 |
| 标题 | 我做的 PPT 又被领导夸了 |
| 笔记链接 | |
| 点赞 / 收藏 / 评论 | 4.8万 / 4.8万 / 210 |
| 发布时间 | 2022-01-18 20:06（是否结合了某些热点时间/事件） |
| 为什么要拆解这篇 | 该博主几篇同类笔记都是爆款，与我的定位相符 |

**Step 2 拆笔记外观**（标题 | 封面 | 封面文案）
- 看到笔记的第一反应是什么？标题里哪些关键词吸引了你？哪些元素促使你打开？
- 示例：封面是一张微信聊天截图（无额外文案）→ 好奇对话细节；标题「我做的PPT又被领导夸了」→ 好奇被夸了什么、她的 PPT 长什么样

**Step 3 拆笔记框架**
- 图文：段落（开头/中间/结尾各什么结构？开头讲故事、讲痛点还是讲干货？正文并列还是递进？用什么方式结尾？）；图片（每张图是什么画面？图上文字的逻辑结构？）
- 口播：提取文案
- 视频：截图、看构图
- 产出一张「分段 | 正文文案 | 逻辑结构」表（范例见 04 的 PPT 笔记拆解）

**Step 4 拆互动行为**（评论区）
- 用户在议论什么——选题本身？某个观点？某个工具/方法？出现最多的关键词？在表达什么情绪？有没有没解答的疑惑？
- 示例归类：「你做的啥样看看」「想要图五的模板」→ 问模板；「图三和图七是用什么软件做的」→ 问软件；「稿定设计不能去水印啊」→ 工具网站询问；作者置顶「后面会推出各种元素查找大汇总」→ 下期预告埋关注钩子。总结：讨论都围绕 PPT 制作本身和笔记里展示的工具网站——**工具网站能吸引用户讨论**

**Step 5 拆爆款因子**（选题 / 吸睛封面 / 吸睛标题 / 痛点 / 痒点 / 内容价值 / 实用工具 …逐项写内容）
用户视角四问：①每张图上什么吸引了你？②正文哪些内容被你记住了？③博主说到哪一句时让你忍不住点赞、收藏、评论？④看完的第一感受？

**Step 6 整理可复用的点 → 我的行动清单**
| 可复用的点 | 我的行动清单 |
|---|---|
| 引起好奇的封面 | 这类封面很火，虽与主页风格不太符，可偶尔用一次测效果 |
| 情绪类标题 | 每周收集 20 个情绪类标题 |
| 信息密度 | 干货笔记给足信息、图文并茂。发布前自检：①是否有 5 个以上知识点 ②是否有足够清晰的图辅助 ③是否结合实用工具让干货落地 |
| 自我介绍页 | 做一张自我介绍图，列出账号几篇爆款标题，引导进主页、提升转粉率 |
| 参考选题 | 这类选题是职场人刚需，可参考 |

### 2. 系统力
- 大量阅读、系统输入：刻意搭建选题库
- 吸收内化、实践输出：一边输入一边输出
- 形成自己的知识库——**卡片笔记法**：把碎片时间输入的内容做成一条条卡片，积累到一定量后按逻辑重新排列组合

### 3. 内驱力
找到初始动力；找到对标人物和账号。

## 二、4 个思维

1. **鲁莽思维：立刻去做**——行动，做出微小成绩；输出（万物皆有信息差）
2. **用户思维：极致利他**
   - 关键问题：内容是不是用户想看的？是不是对别人有用？
   - SOP：
     - 写作前代入用户视角（写作要与用户有关）：这个话题你关心吗？这个封面你想点吗？这个角度与你有关吗？
     - 写作时假装和小学生聊天：把用户当小白，迎合小白的知识水平
     - 写作后做自查清单：
       - 目的：目标用户是谁？要解决他什么问题？他需要哪方面信息？什么内容能让他感兴趣？要达到什么目标、如何衡量？
       - 希望用户什么反应：点赞←激发情绪价值；收藏←提供内容价值；评论←存在讨论点、争议点
       - 是否通俗易懂：知识水平如何？是否匹配用户理解水平？
3. **作品思维：用自媒体放大个人品牌价值**——精心打磨每一篇；用笔记放大个人价值
4. **长期主义：不下牌桌**——以季度、年度为单位设目标，不在意一城一池得失；看数据专注内容本身、只和自己比；用长期主义做内容

## 三、内容生产流程（原文末尾流程图）

```
主题策划 → 细分选题 → 内容检索 → 进入灵感库 → 是否选题？
                                        ↑否 ─────┘   │是
                                                     ▼
                                   内容撰写 → 数据追踪 ─┐
                                      ▲   持续优化     │
                                      └───────────────┘
```

- 不选的题不丢，进**灵感库**留着下次再判断
- 写完不是结束，**数据追踪 → 持续优化**回到撰写，形成闭环（对应 05 的复盘与 2/4/12/24/48h 监测）
