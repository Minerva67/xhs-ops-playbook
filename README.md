## 核心 knowhow（能一眼带走的部分）

### 1 · 推送是流量池，一级一级放大

```
发布 → 审核(机器+人工) ─不通过→ 限流/停推
          │通过
          ▼
       流量池 A ─数据好→ 流量池 B ─→ … ─→ 流量池 N
          │数据不好
          ▼
        停止推荐
```

决定笔记能不能进入下一级的，是点赞、收藏、评论、弹幕、转发、关注这几项数据。所以**发布后头几个小时的数据决定了这篇能走多远**。发布时间要固定，并在 2 / 4 / 12 / 24 / 48 小时各记一次数据。

### 2 · 定位不是「我想做什么」

**商业模式定位 = 变现方式 + 人群 + 需求**

先定变现方式，再倒推内容。顺序反了，做出来的就是只有自己爱看的号。

选赛道问三个问题，任何一个过不了就淘汰：
- **赚钱**：品牌会不会投这个赛道？其他博主是怎么接广告的？
- **喜欢**：你有没有动力一直写下去？
- **擅长**：能不能当场列出 10 个以上选题？列不出来就放弃这个赛道

人设靠三件事立住：**特征**（你是什么样的人）、**身份**（职业或角色）、**场景**（反复出现的环境）。可以用这些手段强化：语言风格、内容调性、固定开头和结尾的话术、拍摄环境。

### 3 · 对标账号先看两个比值，看完再决定要不要对标

| 比值 | 判定 |
|---|---|
| 粉丝 :（赞+藏）≈ 1:10 | 分水岭 |
| 明显低于 1:10（如 1:20） | 有爆款但不涨粉，多是没有人设的工具号 |
| 远低于 1:10 | 不适合做对标 |
| 赞 >> 藏 | 偏情绪，内容没有收藏价值 |
| 藏 > 赞 | 优质干货 |

优先找这三类账号做对标：粉丝不到 10 万的小博主、最近涨得快且更新稳定的号、入驻不满两年的号。

### 4 · 爆款靠因子叠加，不靠灵感

每篇笔记至少凑齐 3 个爆款因子，不到 3 个就别发。

| 类别 | 因子 |
|---|---|
| 需求点 | 痛点 / 痒点 / 爽点 |
| 笔记 | 吸睛封面 / 吸睛标题 |
| 价值 | 情绪价值 / 内容价值 |
| 形式 | 工具 / 清单 / 合集 |

**痛点的五个母题**（先按场景罗列痛点，再归到这五类里）：
- 与钱有关：免费资源、薅羊毛
- 走捷径：省时、省力、速成
- 比较：替用户说出焦虑，再给解法
- 羡慕：晒成绩、晒物品，再给方法
- 宣泄情绪：替用户宣泄，或者劝用户别宣泄

**选题受众要广**：
- ❌「30 岁生日 vlog」——只有你自己关心
- ✅「30 岁财务自由，关于财富的 3 点认知」——所有人都关心

### 5 · 涨粉是乘法，不是加法

```
涨粉数   = 阅读量 × 转粉率
转粉率   = 内容优质 + 人设鲜明
关注动机 = 长期有用 + 提供稀缺
```

数据差时，先分清是哪个变量出了问题：
- 阅读量低：选题、封面或标题有问题
- 阅读正常、赞藏也好，但不涨粉：工具类内容太多，或者个人特色不明显，或者偏离了账号定位

稀缺有四种来源：标签稀缺（经历、职业、身份、性格）、颜值稀缺、内容稀缺（某类内容只有你能发）。

### 6 · 一条笔记值不值，看阅读:点赞

| 阅读 : 点赞 | 判定 |
|---|---|
| ≈ 10 : 1 | 基本能成爆款 |
| 10:1 ~ 20:1 | 流量会涨，但不明显 |
| ≈ 30 : 1 | 普通笔记，价值低 |

还有一条：点赞多于收藏，说明情绪价值高；收藏多于点赞，说明实用性强，后者通常会有持续流量，但能持续多久不确定。

### 7 · 标题六公式（硬线：≤20 字符，1 秒看懂）

1. **引起好奇**：用感叹惊讶式或揭秘类。例：「我不允许有人不知道这件巨无霸可爱外套」
2. **提出疑问**：可以直接发问，例：「我为什么从来不刷短视频？」；也可以问题加解法，例：「眼线不好画？不存在的！2分钟教会你」
3. **多用数字**：必须用阿拉伯数字，有四种用法
   - 价格：用性价比制造反差，例：「13元的折叠收纳筐」
   - 数量：显得内容很全
   - 时间：显得见效快，例：「跳绳30天，减10～15斤」
   - 对比数字：显出巨大差距，例：「从60分到高考141分」
4. **方法集锦**：一个痛点给多个解法，让人觉得马上就能解决。例：「毕业五年收入翻20倍！我做对了四件事」
5. **引发共鸣**：观点要鲜明，带个人色彩。例：「你可以不漂亮，但一定要有生命力」
6. **锁定人群**：标题里放人群词，比如职业、身份、小个子、敏感肌、内向，让目标用户一眼对上号

### 8 · 六种选题法（起号先用前两种）

| 方法 | 一句话 |
|---|---|
| 对标账号法 | 找 1–3 个对标，筛出点赞前十的笔记，分类汇总成选题库 |
| 长尾词裂变法 | 搜大词看下拉框，那些词是系统按真实搜索行为匹配出来的；再按效果、场景、人群、食物等维度组合 |
| 评论区法 | 看对标爆款的评论区，用户看完还没解决的疑问，就是你的下一篇 |
| 热点法 | 创作中心 → 笔记灵感，每周必看。限时热点要快，日常热点提前备稿 |
| 交叉法 | 领域 × 内容形式 × 时间 × 人群 × 价格，交叉组合出选题 |
| 系列法 | 固定栏目、固定时间、系列专题 |

### 9 · 小红书的开头要开门见山

用户点开前已经看过封面，知道要看什么，所以开头少铺垫、直奔主题。这一点和抖音、视频号不一样。脚本模板如下：

- **开头 5 类**
  - 提出问题
  - 描述场景引共鸣（「拆摄像头」式，像跟朋友聊天）
  - 用故事引入
  - 开门见山
  - 发布行动指令
- **正文 2 种**
  - 并列式
  - 递进式
- **结尾 4 类**
  - 总结观点
  - 金句升华，靠的是峰终定律：一段体验的高峰和结尾好，整段感受就好
  - 美好祝愿
  - 预告下期引导关注：能看到结尾的人都是感兴趣的人，预告能直接提高转粉率

### 10 · 发布前后各有一张清单

发布前（节选）：
- [ ] 推到陌生人面前，他会觉得「跟我有关」吗？
- [ ] 标题超过 20 字符了吗？1 秒能看懂吗？
- [ ] 图片里有没有二维码、微信号、其他平台的名字？这是最常见的限流原因
- [ ] 有 3 个以上爆款因子吗？
- [ ] 想要用户点赞、收藏还是评论？这篇能让他这么做吗？
- [ ] 视频：气口剪了吗？字幕有没有错别字？背景音乐有没有盖住人声？

发布后：
1. 用另一个账号看笔记能不能看到，确认审核通过
2. 搜关键词看能不能搜到，确认被收录
3. **查算法给你打了什么标签**：用电脑浏览器打开笔记，右键选「显示网页源代码」，找 `meta name="keywords"`。里面的词就是算法判定的关键词，系统按这些词推人。如果和你想要的人群对不上，说明关键词没植入好，下一篇要改
4. 阅读量低于 100 或卡在 100 左右，可能被判违规，去走申诉

### 11 · 互动是设计出来的

- **评论区问题有 6 类**：推荐、投票、疑问、作业、争议、许愿。例：许愿类「在评论区留言'过过过'，许愿四级一定过！」
- **弹幕指令有 4 类**：场景认同（「有相同情况的扣1」）、留言许愿、情绪感召、预告提示。干货视频的前 10 秒，可以先用自己的账号发一条「先收藏了」
- **评论区放诱饵**：
  - 视频里没讲完的内容，到评论区里吊着，让人留言求下集
  - 下集发布后，回旧笔记置顶，把人引到新笔记
  - 用小号评论某个方法「学到了」，引人回去看，这条方法要放在视频中段，能提高完播率

### 12 · 广告报价

**基准报价 ≈ 粉丝数 × 10%**

在基准价上，看下面几个因素调整：
- 呈现形式：单推高于合集，视频高于图文
- 近 10 篇笔记的点赞和阅读：这一项最关键
- 领域：报价最高的三个是护肤、母婴、美食饮品
- 品牌预算
- 账号调性和品牌的契合度

品牌方挑账号看四点：定位垂直（粉丝和他的目标用户一致）、内容里有植入空间、近期常出爆款、素材能拿去给品牌其他渠道用。想让品牌源源不断找上门，可以在笔记里**加竞品关键词**：品牌投放的逻辑就是搜竞品相关的词，再给出现在结果里的博主投钱。

> 平台门槛类数字来自原文写作时期（约 2022 年）：蒲公英要求 1000 粉、抽成 10%，选品要求 1000 粉，店铺押金 1000 元。用之前以当前官方规则为准。
