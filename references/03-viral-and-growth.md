# 03 如何涨粉、如何做出爆款笔记

三块：**底层规律（互动数据 + 方法）→ 流量密码（爆款类型 + 爆款因子）→ 涨粉核心方法**。

---

## 一、底层规律：推送看互动数据

| 互动数据 | 用户动作 | 核心要点 | 怎么做 |
|---|---|---|---|
| 点击率 = 点击/曝光 | 推荐页点开笔记 | 对封面、标题或选题是否感兴趣 | **选题受众要广**（符合大多数人核心利益：「30岁生日vlog」不如「30岁财务自由，关于财富的3点认知」）；**标题封面要与用户有关** |
| 点赞数 | 点赞 | 是否被喜欢、有无情绪价值 | 让用户情绪波动：感到喜欢/美好/惊艳 |
| 收藏数 | 收藏 | 内容是否有用 | 攻略、教程、合集；加清单、攻略、使用方法 |
| 评论数/弹幕数 | 评论、发弹幕 | 能否引起共鸣、有无讨论点 | 增加互动钩子（见 05） |
| 完播率 | 看完整篇 | 是否吸引人、有节奏感和逻辑 | 内容有层次；镜头感/观众缘、脚本节奏与好奇、画面清晰 |
| 转发数 | 转发到社交平台 | 是否有社交属性 | 情感共鸣、社交货币、行动指令 |
| 关注数 | 看完关注博主 | 内容是否有特色 | 见下文涨粉 |

## 二、方法：三个技巧 + 两个方法

### 技巧 1：戳中痛点
痛点 = 目标用户害怕、恐惧、焦虑、不安、愤怒的点。

操作：**按场景罗列痛点 → 归入 5 类梳理**
| 痛点类 | 做法 / 例子 |
|---|---|
| 与钱有关 | 免费资源（如选校信息网）、平价薅羊毛 |
| 走捷径 | 省时（「3分钟xxx」）、省力、短期速成 |
| 比较 | **替用户说出焦虑**：「为什么你的能力比同事强，升职加薪却轮不到？」「为什么别人都能赚到钱，而你却赚不到？」→ **基于焦虑给方案**：「别赚钱，搞脑，才能和同龄人拉开差距」「不再嫉妒，同龄人的成功不是我的失败」 |
| 羡慕 | 晒优于常人的能力（晒成绩、晒物品）+ 给出方法 |
| 宣泄情绪 | 替用户宣泄情绪 / 阻止用户宣泄情绪 |

### 技巧 2：戳中痒点
痒点 = 用户希望实现的愿望。**尽量让用户看到结果**：「我做不到，但看你做到了很满足」「我想做到，看你做到了就想象自己也能」。

### 技巧 3：戳中爽点
爽点 = 短时间内被满足的需求，传播广、调动情绪。方法：替用户说话（说出他想说的）、释放用户情绪（娱乐、情感类）。

### 方法 1：追热点
- 热点 = 特定时间内很多人关注讨论的事。**前提：和账号定位匹配**
- **有网感**：去目标用户多的地方看他们讨论什么；看对标爆款里用户在讨论什么、发什么弹幕、聊哪些关键词
- **会迁移**（创作者视角）：这个热点戳中了哪些痛点、释放了哪些情绪？这个关键词能迁移到我的领域吗？我的受众也关心吗？
- 分类：
  - **限时热点**（事件/现象、人物）：短期求快（信息类、情绪类选题，写完立即发）→ 中期求优质 → 后期求差异
  - **日常热点（可预判）**：节假日（参考历年爆款）、可预判大事件（如冬奥冠军，提前收集资料写好）、固定节点（618、双11）
  - **热点活动**：官方活动（按官方薯发起的活动做）、笔记灵感里的话题（提高爆款概率）

### 方法 2：成倍增加内容价值
爆款核心 = **能否带来价值**。
- **情绪价值**（看完舒适、快乐、激动）：励志、慕强、治愈
- **内容价值**：
  - 实用内容：攻略、合集、教程——以解决问题为目的，通俗易懂给方案
  - 新知内容：别处看不到——主题稀缺（如「在英国讲历史」）、方法新颖/信息差（例：「还有人不知道微信的这个隐藏功能！！！」——微信文件传输助手做待办，5.9 万赞 3.3 万藏）

## 三、流量密码

### 爆款笔记类型
1. **合集类**：内容丰富、信息量大、全面。按人群/价格/地域/时间/场景/用户需求或产品功能（如「美白」→「美白+痛点关键词」）组织
2. **颜值类**：美好的生活、美好的物品、美好的人
3. **省时类**（帮用户省时间）：
   - 测评类：产品卖点、适用人群，更客观公正
   - 攻略类：从 0 到 1 解决问题
   - 教程类：详细描述产品使用步骤、适合人群和场景

### 叠加爆款因子

| 维度 | 爆款因子 |
|---|---|
| 需求点 | 痛点、痒点、爽点 |
| 笔记 | 吸睛封面、吸睛标题 |
| 价值 | 情绪价值、内容价值 |
| 形式 | 工具、清单、合集 |

- 方法：**写笔记时罗列出这篇的爆款因子**，发布前要 **≥3 个**
- **成倍放大**：极具冲击力的封面和标题、极度夸张的情绪、极度稀缺的干货、互动性极强的评论区

## 四、涨粉核心方法

### 用户行为地图

```
首页刷到笔记
 ├─ 不感兴趣 → 不点击，滑走
 └─ 感兴趣 → 点击笔记
      ├─ 不喜欢 → 跳出
      └─ 被触动 → 点赞 / 收藏 / 评论·弹幕 / 转发 / 直接关注
           └─ 想了解更多 → 进主页 → 看简介 → 粗看整体
                 ├─ 不感兴趣 → 跳出
                 └─ 持续感兴趣 → 细看单篇 → 满足期待 → 关注（否则跳出）
```

### 按流程优化
| 环节 | 抓手 |
|---|---|
| 打开笔记前 | 爆款标题，在封面和标题上多下功夫 |
| 浏览笔记时 | 个人特色：有趣、有价值、不同；突出人设和记忆点 |
| 进入主页后 | 视觉风格统一；简介快速说清账号定位、内容方向、是否符合预期（公式见 02）；内容质量稳定在市场及格线以上、稳定高频更新、符合预期 |

### 涨粉公式
- **涨粉数 = 阅读量 × 转粉率**（转粉率 = 涨粉人数/阅读量 = 给打开笔记的人一个必须关注你的理由）
- **转粉率 = 内容优质 + 人设鲜明**
  - 内容优质：角度新颖、呈现形式独特、干货更多、更容易落地
  - 人设鲜明有记忆点（行为特征要被人喜欢）：鲜明个人标签、强调努力过程、强化语言风格
- **关注动机 = 长期有用 + 提供稀缺**
  - 长期有用：用户发现你能长期提供有价值的内容
  - 稀缺：标签稀缺（经历、职业、身份、性格）、颜值稀缺、内容稀缺（某类内容只有你能发）
