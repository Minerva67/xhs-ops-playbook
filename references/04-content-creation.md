# 04 内容创作：从 0 到 1 写一篇受欢迎的笔记

顺序：**选题 → 封面 → 标题 → 内容（图文结构 / 视频脚本）→ 关键词植入**。

---

## 一、选题

### 6 种选题法

**1. 对标账号选题法**
找 1–3 个对标 → 筛点赞前十笔记 → 分类汇总成「账号爆款选题库」→ 问：集中在哪些话题？哪些关键词高频？有哪些共性？

选题库示例（方向 | 标题 | 赞 | 藏 | 评）：
| 方向 | 标题 | 赞 | 藏 | 评 |
|---|---|---|---|---|
| 自我成长 | 2022年别再荒废！四招让你无痛逆袭！彻底改变 | 39万 | 21万 | 6953 |
| 自我成长 | 2022 年别废掉！三招让你脱胎换骨 | 29万 | 22万 | 3584 |
| 自我成长 | 骂醒不想努力的你！坚持不下去的进来看！ | 22万 | 15万 | 2648 |
| 理财副业 | 10个0成本靠谱兼职！在家也能赚大钱（附平台） | 10万 | 6.9万 | 4435 |
| 理财副业 | 日赚3000元！复旦学姐带你定投基金！小白必看 | 3.6万 | 2.1万 | 418 |
| 情感婚姻 | 36 个恋爱实用话题，越聊感情越深 | 6.5万 | 5.3万 | 402 |
| 学习方法 | 无痛记忆法！一天背500页！过目不忘，逢考必过 | 13万 | 10万 | 2699 |
| 学习方法 | 9个自我提升App，不花一分钱，学霸都在用！ | 2.3万 | 1.8万 | 350 |

→ 共性一眼可见：「数字 + 别废掉/逆袭 + 无痛/0成本」句式反复出爆款。

**2. 长尾关键词裂变法**
选几个领域大词 → 沿长尾词延伸。长尾词 = 搜大词后下拉框/结果页给出的细分词（系统按用户搜索行为匹配的热门关联词）。
- 搜索下拉：「减脂」(1411万+篇) → 减脂餐/减脂晚餐/减脂早餐…；「减脂晚餐」(155万+篇) → 吃什么掉秤/食谱/速食/外卖/上班族/大学生/鸡胸肉/一人食/小基数/宿舍…
- 按 **效果、场景、人群、食物** 等维度组合细分选题
- 搜索结果页的分类标签（减脂 → 减脂餐/运动/计划/好物推荐/食物）：排名靠前的笔记权重高、质量有保障，且按时间热度更新，可持续关注
- 第三方长尾词工具：5188

**3. 评论区选题法**
分析评论区：哪些词高频？用户在讨论什么？看完后的疑问？在表达什么情绪？
- 例：评论要购买链接 → 物品被种草了；评论在争论观点 → 可引入个性化观点做下一篇

**4. 热点选题法**
渠道：小红书 创作中心 → 笔记灵感。注意：速度够不够快（了解程度、创作难度）、能否满足用户需求、有没有差异化（独特观点、差异化角度）。

**5. 交叉选题法**
选题构成要素：**领域 × 内容形式 × 时间 × 人群 × 价格**，交叉组合出新选题。

**6. 系列选题法**（一定周期内重复做）
- 固定栏目：按账号定位设更细分的垂直选题
- 固定时间：每年/季/月/周固定某天发某类主题（月度书单、本月好物开箱）
- 系列专题：围绕大事件或特定节点做一系列内容

### 搭建选题库
- **对已有爆款做减法**：从爆款选题里筛出符合自己人设、能力、知识储备的
- **搭建自己的知识体系**：明确自己的关键词 → 把想分享的选题罗列成思维导图框架（具备哪些能力？欠缺哪些知识？）→ 获取知识 → 内化实践 → 形成体系

## 二、封面

### 底层逻辑
| 逻辑 | 做法 |
|---|---|
| 反差对比 | BA 图（before / after） |
| 视觉冲击 | 引起好奇（没听过的方法/工具）；冲突悬念（反常识）；**大字报**——突出重点、简洁明了 |
| 极具美感 | — |
| 引起好奇 | **信息量大**（手机备忘录截图、手写笔记，如「我只做三件事/我只看三种书」）；**内容丰富**（拼图类，如「学生党水乳大盘点」）；**未展示全貌** |

### 制作要点
- 宽高比：图片建议 **3:4**，尽量全号一致
- 工具：海报类用 Canva、创可贴、稿定设计；实拍类用醒图、黄油相机
- 注意：整体调性统一；**不断重复使用自己的封面流量密码**（重复爆款、复盘总结）

## 三、标题

### 6 个标题公式（附原文例句）

**1. 引起好奇**
- 感叹惊讶式（配吸睛封面用）：「告诉我我不是最后一个知道的！！！」「我不允许有人不知道这件巨无霸可爱外套」「天呐，一个日历做得这么好看！」「我再说一遍！它俩是内衣界的天花板啊」
- 揭秘类（常带反常识）：「坦白局！网红收入差这么多？哪种网红最赚钱」「跟年薪70w的95后聊了，他说赚钱不靠拼命」「早点知道就好了，毛孔粗大草莓鼻真相！」

**2. 提出疑问**
- 直接疑问：「我为什么从来不刷短视频？」
- 问题 + 解决方案：「眼线不好画？不存在的！2分钟教会你」「如何逼自己瘦下来？微胖女孩的超强逆袭」「为什么酒店的水蒸蛋总是那么嫩滑，我来教你」

**3. 多用数字（一定要阿拉伯数字，一眼可见）**
- 价格（种草类，性价比写进标题；配看起来很贵的封面形成反差）：「我又在xxx上挖到宝啦！13元的折叠收纳筐！附链接」「花了2元！我终于第一次自己画出下睫毛了！！！」「花了10万元装修好的103平小家，有那么廉价吗？」
- 数量（营造多而全）：「便宜又好用！5个皮肤科好物分享给姑娘们」「6部高分育儿纪录片，胜过看10本育儿书」
- 时间（见效快、速成）：「10分钟做抱蛋肥牛饭！酱汁浓郁太下饭啦」「跳绳30天，减10～15斤，双倍燃脂的快乐！」「7天6个offer，恭喜我求职密码算拿捏住了」
- 对比数字（巨大差距）：「又拿offer了！10个面试回答，竟然涨薪50%」「数学分数从平时考60分到高考考141分，我只用了这3个方法」「104-90斤！小基数减肥方法大公开！」

**4. 方法集锦**（针对一个痛点给多个方案，营造轻松、短平快、立即解决的感觉）
「学会这三招，你也能快速写出一篇爆款笔记」「'熊孩子'不听话，用这几个方法让他秒变小天使」「毕业五年收入翻20倍！我做对了四件事」「4个高效时间管理法，悄悄看完'卷哭'同龄人！」

**5. 引发共鸣**（明确表达观点，带鲜明个人特色；想清楚怎么论证、认同点与反对点）
「为什么你不需要对讨厌你的人'自证清白'」「主动的女生太酷了，太让人羡慕了！」「你可以不漂亮，但一定要有生命力」

**6. 锁定人群**（植入人群词，让用户在推荐页对号入座）
人群维度：职业、身份、特征（小个子、敏感肌）、性格、行为（内向、不合群）。

### 持续写出爆款标题的 3 个技巧
1. **模仿爆款句式**：用户熟悉某类话语体系后，再刷到同类标题会默认你也能提供同等价值，从而点开
2. **植入高频关键词**：搭爆款标题库；第三方（千瓜数据等）批量下载 → 微词云做词云 → 统计爆款关键词、筛出适合自己的记入标题库 → 词义分析（哪些表达情绪？什么情绪？戳中什么痛点？哪些是网络流行热词？）
3. **重复使用自己已有的爆款标题**：分析已有笔记，爆款反复复用

## 四、内容

### 图文笔记结构
- 以图为主、文字为辅：教程类（逐步展示步骤）、种草类（如家居）
- 以文字为主、图为辅：传达情绪价值，或干货/认知类内容价值
- 图文相辅相成
- 排版：**多换行、多空行、多用 emoji**

**图文拆解范例（「只会做PPT的咨询顾问教你的绝招，请收好！」）**
| 分段 | 写法 | 逻辑结构 |
|---|---|---|
| 开头 | 「咨询顾问除了会做PPT还能做什么？…不多说，直接上干货！」 | 开门见山 + 身份背书 |
| 中间① | 快速做PPT的 5 个流程：明确受众 → 构建框架（不要先做PPT！）→ 填充内容 → 按风格找模板 → 在线设计 | 递进式 |
| 中间② | 3 个必备思维：结构化思维（标题+一句话解释）；视觉思维（标题+解释+举例：颜色≤3种、大段字别用衬线体）；故事思维（标题+解释+工具：SCQA 情景-冲突-疑问-回答） | 并列式，案例用图片详细展示 |
| 结尾 | 「我是鬼鬼，我们下次再见啦」 | 自我介绍，加深印象 |
| 话题 | #打工人效率神器 #办公软件使用技巧 #PPT实用技巧 #职场 … | 话题标签增加搜索权重 |

### 视频脚本结构

**开头（5 类）**
1. **提出问题**
   - 痛点 + 解决方案：「时间不够用如何规划？每天忙得不可开交的你如何重新掌控节奏？」→「这本书给出了最好的答案。」
   - 观点 + 自问自答：「20多岁的女孩把钱都花在学习上，能有什么收获呢？」→「我是一个出身普通的姑娘…我做得最正确的决定是，舍得在学习上花钱。」
   - 问题 + 成绩背书 + 解决方案：「你敢不敢和我一起用一年的时间改变自己？」→ 连列 4 个「我曾用一年的时间……」→「这期视频我将从时间管理、任务管理、目标管理三个维度……」
2. **描述场景，引起共鸣**（描述用户正在经历的事）
   - 引起情绪波动：指出多数人在犯的错/认知误区——「新手学化妆，步骤和化妆品都和博主一样，为什么效果差别这么大？」「如果你还在给孩子看这几部动画片，请立刻停止！」
   - 「拆摄像头」（像和朋友聊天）：先描述痛点「刚开始学化妆，画出来的总是这种无效妆容」→ 再给方案「今天这个新手万能化妆公式……全都是精华，放到视频最后，看完赶紧截屏保存」
3. **用故事引入，引起好奇**：「我刚面试完出来吃饭，感觉这次又要拿offer了。岗位写10K，我谈到了15K……这套面试话术真的太牛了！」
4. **开门见山、直入主题**——**小红书和抖音/视频号的区别**：用户先看封面判断是否感兴趣，打开前已有预期，所以开头直奔主题、少铺垫
   - 直接分享观点：「听我一句劝，厨房里这三种东西千万别买」
   - 直接分享主题：「挑战10元做晚饭之第18天」
5. **发布行动指令**：「姐妹们，我淘到宝了！」「刷到的人，请立刻停止做这三件事，否则你的人生会越来越糟。」「千万不要滑走，这是一条干到不能再干的视频。」「首先给看到这条视频的你鼓掌，因为我帮你省去了超贵的咨询费。」

**正文**
- 并列式（任一部分互换不影响整体）：方法1/2/3、好物1/2/3
- 递进式（有逻辑顺序，不能互换）

**结尾（4 类）**
1. 总结观点、加深记忆：「以上5个步骤你们记住了吗？费曼学习法…赶紧用起来吧！」
2. 金句升华、明确立意（**峰终定律**：高峰和结尾体验愉悦，整段体验就愉悦）：升华观点、名人金句、热门影视剧金句
3. 美好祝愿、调动情绪：「大家赶紧收藏起来，跟着视频一起练起来，相信你很快也会瘦掉小肚子」
4. 行动指令、埋钩子：
   - 引导互动：「下期告诉你面试有哪些加分细节…还没找到好工作的可以在评论区许愿，很灵哦」
   - **预告下期引导关注**（能看到结尾的人一定对内容或博主感兴趣，预告系列内容→怕错过就关注→提升转粉率）：「口播视频的开头文案该怎么写…我拆解了几十篇爆款视频笔记的脚本，总结出几类万能模板，点赞和关注，下次分享！」
   - 多个动作组合：「以上三件事，请在公屏上告诉我你中了几个……相信自己可以的，就点赞，给我，也给你自己鼓鼓劲吧。」

## 五、关键词植入（SEO）

**底层逻辑**：曝光来自算法推荐（按关键词千人千面）+ 用户搜索 → 在标题、正文、话题布局关键词。

### 找关键词的 3 个方法
1. **用户行为倒推**：设想用户遇到什么问题会对这篇感兴趣、会搜什么词；或用长尾词工具看相关高频需求词，倒推用户习惯
   - 例：「减脂餐」高频需求词有 做法/食谱/一周/晚餐/鸡胸肉/好吃 → 正文开头写「鸡胸肉怎么做才能好吃？今天的一周食谱系列，为大家分享鸡胸肉减脂餐的做法，减脂期晚餐必备，在宿舍、在家一人食也能轻松搞定！」
2. **平台热榜与第三方榜单**：创作中心-笔记灵感（官方热门话题）；千瓜、新红看短期增量多的词（热点事件 & 时间节点），融合进笔记
3. **参考同类选题的关键词**：不知道选哪个词时，看同类爆款加了什么

### 布局位置
- **标题**：让感兴趣的人在信息流看到；带精确关键词更易被搜到。与 数字/网络词/情绪/人群 组合：
  - 数字+关键词：「无废话总结！9款眼霜红榜！实打实好用！」
  - 网络词+关键词：「我真的会谢！这款鸡胸肉太好吃了！绝绝子！」
  - 情绪词+关键词：「我不允许有人不知道这款水光仪！赶紧给我入手」
  - 人群+关键词：「学生必备的洗面奶，便宜大碗不伤皮肤！」
  - 测评笔记植入热门品牌词：「超详细测评 Apple Pencil vs 电容笔，哪个更好用？」
- **正文**：开头、中间、结尾都出现，提高关键词密度；测评可放多个品牌名，搜任一个都可能搜到
- **结尾**：以话题标签形式植入，增加搜索权重
