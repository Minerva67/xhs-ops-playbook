# 小红书运营打法 · xhs-ops-playbook

> 把一份《小红书运营》学习文档（正文 + 7 张思维导图 + 60 张配图）逐字提炼成一个 Claude Skill。它不复述道理，而是**按你卡在哪一步**直接给出改法：定位、对标拆解、选题、封面、标题、脚本、SEO、互动钩子、复盘、变现。

## 它能干什么

| 你说 | 它做 |
|---|---|
| 「帮我看看这篇笔记为什么没流量」 | 判断卡在点击、内容还是转粉 → 套比值阈值 → 清点爆款因子 → 给出改后的封面、标题、开头和结尾 |
| 「帮我写一篇 / 改一篇笔记」 | 给出选题、封面逻辑、3 个标注了公式的标题、脚本结构、关键词布局、互动钩子和发布前自检 |
| 「我想起个号 / 不知道做什么」 | 依次走五个定位 → 三项打分 → 拆 3 个对标 → 输出定位卡、名称和简介 |
| 「拆一下这个博主 / 这篇爆款」 | 填对标拆解表，或走单篇五步拆解，最后整理成行动清单 |
| 「帮我复盘这周数据」 | 填单篇复盘表、周/月复盘表和生死线表 |
| 「怎么接广告 / 报价多少」 | 给出变现方式、报价公式及修正项、商单 SOP |

## 常用阈值（节选）

- 对标账号的粉丝 :（赞+藏）以 **1:10** 为分水岭，远低于这个比例的账号不适合当对标
- 单篇阅读 : 点赞约 **10:1** 基本就是爆款，约 30:1 属于普通笔记
- 发布前爆款因子要有 **≥3 个**；标题 ≤20 字符；封面用 3:4；同一种封面风格至少测 10 篇
- 广告报价 ≈ **粉丝数 × 10%**；单推比合集贵，视频比图文贵

> 平台门槛类数字来自原文写作时期（约 2022 年），用前以当前官方规则为准。

## 安装

**Claude Code**：把整个文件夹放到 `~/.claude/skills/xhs-ops-playbook/`，重开会话即可自动加载。之后直接说「帮我看看这篇小红书笔记」，或者用 `/xhs-ops-playbook` 调用。

**Claude 网页 / App**：把仓库打成 zip，在 Settings → Capabilities → Skills → Upload skill 上传。
