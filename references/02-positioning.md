# 02 如何策划一个账号：定位 → 对标 → 测试 → 设计账号

三大块：**账号定位（五个定位）→ 定位步骤（找对标、拆对标、测方向）→ 设计账号（名称/头像/简介/视觉）**。

---

## 一、账号定位（五个定位）

### 1. 商业模式定位 = 变现方式 + 人群 + 需求

**先明确变现方式：**
- **产品变现**：用小红书引流到其他平台成交。目的是扩大影响力、引流；方法是发垂直领域内容、吸引精准粉丝。
- **流量变现**：靠流量多维度变现（广告、带货、专栏…，详见 06 变现方式表）。路径：明确目标 → 优质内容 → 提升报价。
  - 优化账号数据：互动数据反映粉丝粘性
  - 提升垂直度：广告主看「是否垂直」「粉丝与目标用户的匹配度」
  - 提升账号质量：专业度

**再明确目标人群：** 为什么人、解决什么问题——吸引哪个身份？哪个年龄？这群人的需求和问题是什么？

### 2. 赛道定位：优势 × 兴趣

- **有长板**（学历、成绩、经历优势）：职业优势、学校背景、经历
- **无长板**：从兴趣出发，或做「养成系博主」

**方法 A：成就事件提炼法**

```
成就事件 ─┬─ 事件1 → 能力1 / 能力2 / 能力3
          ├─ 事件2 → 能力1 / 能力2 / 能力3
          └─ 事件3 → 能力1 / 能力2 / 能力3
```
列出每件做成过的事（哪怕很小），从每件事里拆出 3 个能力，能力的交集就是可选赛道。

**方法 B：定位剖析表**

| 项目 | 填写说明 |
|---|---|
| 身份/职业标签 | 学历、职业经历 |
| 成就事件 | 取得过的成绩，哪怕很微小也列出来 |
| 拥有的能力 | 从成就事件中剖析出现阶段的硬技能、软技能 |
| 时间和精力 | 能花多少时间运营、这件事的难易度 |
| 现有产品 | 如果有变现产品，在此梳理 |

**取舍打分表（赚钱 × 喜欢 × 擅长）**

| 领域 | 赚钱（自我剖析/打分） | 喜欢（自我剖析/打分） | 擅长（自我剖析/打分） | 总分 |
|---|---|---|---|---|
| 领域 A | | | | |
| 领域 B | | | | |
| 领域 C | | | | |

- **赚钱**：有没有市场前景？品牌投放市场如何？其他博主怎么接广告？内容形式能否承接？
- **喜欢**：有没有内驱力持续输出？
- **擅长**：难易度如何？基本能力是否具备？**能不能列出 10 个以上选题**（列不出来=不擅长）

### 3. 内容定位

**主题定位：**
- 主题类账号：围绕某主题做垂直内容「洗粉」（如每天拆解一个领域名词、小个子穿搭）
- 泛垂直账号：围绕赛道主题做多元内容
- 人设类账号：适合强真人出镜

**形式定位 — 图文：**

| 呈现形式 | 特点 |
|---|---|
| 实拍景物/产品图 | 主流形式之一，需要一点拍摄或修图能力 |
| 实拍真人图 | 主流形式之一，需要一点拍摄或修图能力 |
| 海报 | PPT/PS/设计网站模板制作，门槛低但需要设计审美 |
| 截图 | 画面、文字截图呈现，门槛低但缺乏个人特色 |
| 拼图 | 单种或多种元素拼成一张图，测评、plog 常见 |
| 伪实拍图 | 用无版权现成图代替自拍，适合不太会拍照的新手 |

**形式定位 — 视频：**

| 呈现形式 | 特点 |
|---|---|
| 真人出镜口播 | 适合知识/技能/干货博主，要求镜头表现力和文案功底 |
| 不出镜实拍场景 + 配音 | 新手易入门，对场景与选题有要求 |
| 不出镜实拍场景 + 背景音乐 + 字幕 | 新手易入门，多为 vlog，对场景与选题有要求 |
| 混合：真人出镜 + 不出镜实拍 | 想打造 IP 但全程口播表现力不够的博主；多形式组合增强节奏感 |
| 素材剪辑 + 配音 | 影视综艺/无版权素材拼接服务主题；新手好入门但人设不强 |

### 4. 人设定位

**组成 = 特征 + 身份 + 场景**
- **特征（你是什么样的人）**：自我剖析 + 请他人描述后分类汇总
- **身份**：职业身份（特定领域里的身份）、角色身份（特定场景里的身份）。可以多个身份，但要反观赛道和内容，哪些标签该放大、哪些无关
- **场景**：图文里呈现的场景

**自我剖析备用问题（附示例答案）**

| 问题 | 示例 |
|---|---|
| 有哪些事情是我每天都必须做的 | 读书、写作、做计划、复盘、做早饭、听播客 |
| 做什么事时我容易激动、进入专注 | 剪视频容易忘记时间，剪完很有成就感；做创意文案很带劲 |
| 有哪些事我坚持了一年以上 | 读书、复盘、写作 |
| 我的性格是怎样的 | 内向、慢热、说话比较直接 |
| 我有什么优点、缺点 | 优点：学习能力强、肯钻研；缺点：不自信、公开表达弱 |
| 哪些曾是我的弱项，但通过努力改变了 | 害怕当众演讲 → 学写作学会结构化表达 → 汇报让领导觉得靠谱 |
| 我对自己什么部位/特点最满意 | 长相一般但有趣；执行力强、说到做到 |
| 身边人给我起什么外号 | 催稿狂魔、工作狂 |
| 做什么事时总得到身边人赞美 | 会写有意思的打油诗，大家觉得有才 |
| 朋友遇到什么事总会找我帮忙 | 想找人写文案时第一时间找我，付费找我写 |

**如何强化人设：** 语言风格；内容风格（调性、价值观）；固定话术植入心智（固定开头「hello 我是 xxx」、固定结尾强化人设标签）；环境强化。

### 5. 差异化定位

性格差异化 / 内容形式差异化（表现形式、包装形式）/ 身份标签差异化 / 道具差异化。

## 二、定位步骤

### Step 1 搜索对标账号，细分垂直方向

找对标的 7 个渠道：
1. **主动搜索**
   - 搜用户
   - 搜泛关键词（目标赛道词）→ 分析笔记（选题角度、对应人群、图文形式、视频画面形式）→ 给笔记分类（呈现形式、工具、种类）
   - 搜细节关键词：列出可能的细分词逐个搜，筛权重高的优质笔记 → 找到更细分的对标
   - 分析博主：第一感觉？我会怎么给他打标签？整体风格是我想做的吗？我也能做吗？
2. **算法推荐**：打开个性化推荐，调教大数据，让系统推对标
3. **对标账号的关注列表**
4. **共同关注**：关注后看「推荐」里的类似风格博主
5. **官方薯**（见 01）
6. **第三方工具**（千瓜、新红等）

### Step 2 拆解对标账号，明确调性

**选哪类账号做对标：** 小博主（粉丝 < 10 万，看选题/风格/人设）、近期发展迅速 + 更新稳定的账号、入驻两年内的账号。

**拆解四块：基本信息 / 调性 / 商业模式 / 可借鉴的点**

**① 基本信息 — 看数据判断能不能对标**
- **粉丝数 :（点赞+收藏）= 粉丝转化效果，分水岭 1:10**
  - 小于 1:10（如 1:20）：有爆款但不涨粉，常见于「没有人设的工具号」
  - 远小于 1:10：**不适合做对标**
- **点赞数 : 收藏数 = 笔记价值**
  - 点赞 >> 收藏：不具有收藏价值（偏情绪）
  - 收藏 > 点赞：优质干货内容
  - 差距不大：参考整体风格和内容；差异很大：分析是情绪价值、内容价值还是干货价值导致
- **第一篇笔记发布时间**：倒推用了多久拿到这些粉丝
- **近 3–6 个月更新频率与发布时间段**：更新稳定 + 固定时间发 → 参考其更新规划
- **多平台布局**：其他平台有没有号

**② 调性**
- 细分方向：在什么赛道、垂直分享什么？我有没有能力做？在更细分领域创作了哪些内容、靠哪些内容出爆款、我是否具备这种创作能力？
- 人设：性格特征、文案风格、博主故事；看评论区——靠什么特质吸引人？
- 呈现形式：图文（实拍/海报）；视频（形式、平均时长、横版 or 竖版）

**③ 商业模式**
- 如何变现：广告（合作品牌？集中类目？）/ 引流（产品是什么？客单价？）
- **如何识别接广**：
  - 标签：报备合作会在开头几秒显示「赞助」；不报备合作常带品牌标签
  - 笔记本身：大篇幅描述产品（软广）、合集里排前几位的产品、一个周期内多次发同一产品

**④ 可借鉴的点**
- 崛起点（流量密码）：从哪篇开始快速涨粉？按时间顺序找点赞、收藏最高的笔记
- 可复用点：爆款标题？视频结构？开头介绍方式？结尾金句？

**对标总结四问：** 总体感受？调性/内容定位/呈现方式/变现方式与我想做的是否契合？如果我来做，能做吗？有什么可改进的？

**注意：** 对标账号是否做过大调整（调了什么、什么因素导致爆款）；对标可以更换；要对标多个维度。

**对标拆解表（模板 + 示例）**

| 账号昵称 | 粉丝数 | 粉丝:(赞+藏) | 赞:藏 | 首篇发布时间 | 近3–6月更新频率与时间 | 多平台 |
|---|---|---|---|---|---|---|
| 兔姐Cheryl | 1.8万（赞4.6万/藏5.6万/124篇） | 约 1:5 | 约 1:1.2 | 2021-08-21 | 一周 4 条，18:00–22:00，不固定 | 无 |

| 细分方向 | 人设 | 呈现形式 | 报备合作 | 不报备合作 | 崛起点 | 可复用的点 |
|---|---|---|---|---|---|---|
| 健康教程 | 健康、阳光 | ①图文实拍（室内/户外+彩色运动服）②视频：运动动作讲解 | 运动服、鞋及周边 | 无 | 臀部训练教程、拉伸训练、直角肩视频 | 封面视觉冲击（形体+彩色运动服）；运动配饰丰富 |

示例对标总结：①调性契合，可作主要对标；②动作讲解类视频爆款多，做这类视频时参考；③封面突出身材曲线。

**对标最终输出（定位卡）**

| 项目 | 填写 |
|---|---|
| 我的赛道和用户定位 | |
| 我的对标账号（账号名 + 链接） | |
| 我的变现方式 | |
| 我的人设 + 场景设计 | |
| 我的呈现形式 | |

### Step 3 测试方向，形成独家风格

- **阶段 1 模仿**：选题**必须借鉴**（想清楚戳中了什么痛点）；观点和方法**必须独立**（内核是你自己的）；呈现形式**部分借鉴**
- **阶段 2 形成风格**：做出爆款 → 复制套路 → 做出成绩、形成标签

## 三、设计账号

### 名称：3 原则 + 4 方法
- 原则：没有阅读难度、没有称呼难度、有记忆点（可与内容结合）
- 方法：
  1. **名字/称呼 + 领域/职业/学校/身份**：xx的装修日记、摄影师xx、学姐xx、xx妈妈（融入内容方向、爱好特征）
  2. **名字/称呼 + 地域**：地域与内容或人设有关时
  3. **地域 + 领域 + 名字/称呼**：产品依托线下销售时，用来筛同城精准用户
  4. **直接用名字/称呼**：做个人品牌

### 头像
真人照片 / 卡通头像 / logo。

### 简介

**简介问答表（每一项的作用）**

| 自我介绍项 | 作用 |
|---|---|
| 人设标签 | 你有哪些独特经历、想展现哪些特质 |
| 身份标签 | 展现身份背景，获得信任 |
| 个人基本信息 | 向垂直用户展示基本信息吸引同类（穿搭→身高体重；护肤→肤质；家居→房屋面积） |
| 内容定位 | 你分享什么、关注你能得到什么 |
| 成就事件 | 取得过什么成绩、与别的博主有什么不同 |
| 关注预期 | 给用户一个关注你的理由 |
| 一句话 Slogan | 一句金句传递价值观，或一句话呈现账号特色 |
| 联系方式 | 让合作品牌能联系到你 |

**简介公式（原文画板列 4 个，配图列 5 个，合并如下）**
1. 身份标签 + 成就事件 + 内容定位
   - 「互联网女工｜独立摄影师 / 初中被开除—互联网大厂—上市集团AI项目经理 / 分享可复制的方法论」
   - 「剑桥认知科学PhD在读 / 国内985退学—美本top30—剑桥PhD全奖 / xxx」
2. 人设标签 + 成就事件 + 内容定位（强化人设特征、放大情绪价值）
3. 成就事件 + 身份标签 + 产品服务成就 + 内容定位（有产品/服务时）
4. 个人特征 + Slogan
5. 关注预期 + 内容定位 + 身份标签 & 成就事件 + 个人基本信息
   - 「关注我，带你DIY留学 / 留学博主｜DIY玩家｜留学工作室 / 美本Top30｜剑桥PhD 留学创业ing / 国内985退学—DIY美本top30—剑桥PhD」
   - 「国内普高—985退学—Umich本硕满绩—剑桥全奖PhD在读 / TOEFL112｜SAT 1560｜GRE 335 / 关注我，带你全程DIY留学」

### 视觉设计（整体风格决定第一印象）
- **图片风格统一**：让人一眼知道你是做什么的、带来什么价值、给一个关注理由；先想好封面风格再创作内容；可参考对标；前期可测不同风格，但**同一种风格至少测 10 篇**，别频繁换
- 字体风格统一
- 内容风格极度垂直，发布内容符合用户预期
