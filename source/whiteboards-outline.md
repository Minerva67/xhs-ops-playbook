    -  商业模式定位=变现方式+人群+需求

            -  提升账号质量

      - 明确目标人群

- 如何做出爆款笔记
  - 底层规律
    - 推送关键因素：互动数据 [图:AuN0bhAPTot738xcaT1c5S06nvg]
      - 点击率：点击数/曝光量
        - 选题：受众要广 ⏎ 决定用户是否对内容感兴趣
          - 符合大多数人的核心利益 ⏎ 30岁生日vlog vs 30岁财务自由，关于财富的3点认知
        - 标题和封面：要吸引人 ⏎ 决定用户是否想进一步了解
          - 要与用户有关 [图:RHnpbooxloEVAhxZSHEcmia4nOc]
      - 点赞数
        - 要让用户产生情绪波动
        - 场景
          - 感到喜欢
          - 感到美好
          - 感到惊艳
      - 收藏数
        - 要让用户觉得有用 ⏎ 攻略类、教程类、合集型笔记
        - tips
          - 加入清单类、攻略、使用方法
      - 评论数、弹幕数
        - 增加互动值零
      - 完播率
        - 让内容有层次
        - 完播率因素
          - 镜头感、观众缘
          - 脚本文案是否有节奏感、是否能引起用户好奇
          - 画面是否清晰
      - 转发数
        - 让内容带有社交属性
        - 场景
          - 产生情感共鸣
          - 拥有社交货币
          - 获得行动指令
      - 关注数 ⏎ 看了你的笔记关注你的人数
    - 方法
      - 三个技巧
        - 戳中痛点 ⏎ 罗列某一场景中的具体痛点和梳理人们普遍存在的痛点，从而更了解用户对什么内容感兴趣，以便创作内容。
          - 痛点
            - 目标用户害怕、恐惧、焦虑、不安、愤怒的点
          - 操作步骤
            - 罗列痛点
              - 按照场景分类，在每个场景中罗列出痛点
            - 梳理痛点 ⏎ 与钱有关、走捷径、比较、羡慕、宣泄情绪
              - 与钱有关
                - 免费资源类
                  - 选校信息网
                - 平价薅羊毛
              -  走捷径
                - 省时
                  - 3分钟xxx
                - 省力
                - 短期速成
              - 比较
                - 替用户说出焦虑 [图:HTNSbTiwWo78kLxsuLpc6GVvngg]
                - 基于焦虑给出解决方案 [图:ZMSxbQ5haojIssx86U1cFkGcnIc]
              - 羡慕 ⏎ 晒优于常人的能力 ⏎ 给出方法
                - 晒成绩
                - 晒物品
              - 宣泄情绪
                - 替用户宣泄情绪
                - 阻止用户宣泄情绪
        - 戳中痒点
          - 痒点
            - 用户希望实现的某些愿望
          - 尽量让用户看到结果
            - 我做不到，但看你做到了很满足
            - 我想做到，看到你做到了就想象着自己也能做到
        - 戳中爽点
          - 爽点
            - 短时间内被满足的需求
            - 特点
              - 广泛传播
              - 调动用户情绪
          - 方法
            - 替用户说话 ⏎ 替用户表达想表达的
            - 释放用户情绪 ⏎ 娱乐、情感类博主
      - 2个方法
        - 追热点
          - 热点
            - 特定时间内很多人会关注和讨论的事情
            - 注意：是否和自己的账号定位匹配
          - 方法
            - 有网感 ⏎ 什么样的热点适合自己
              - 如何训练
                - 到目标用户多的地方，看他们讨论什么
              - 对标账号爆款笔记
                - 用户在讨论什么
                - 在发什么弹幕
                - 用户在讨论哪些关键词
            - 会迁移 ⏎ 从创作者视角进行审视
              - 这个热点戳中了哪些痛点？释放了哪些情绪
              - 这个关键词能否迁移到自己的创作领域
              - 你的目标受众是否也关心这个？
          - 分类
            - 限时热点
              - 分类
                - 热点事件/现象
                - 热点人物
              - 实操
                - 短期内求快：短时间内写出笔记并立即发布
                  - 信息类选题
                  - 情绪类选题
                - 中期求优质
                - 后期求差异性
            - 日常热点 ⏎ 对热点的预判
              -  节假日热点
                - 参考历年的爆款笔记
              - 可以预判的大事件
                - 冬奥会冠军等
                - 提前收集资料、写好笔记
              - 固定时间节点的事件 ⏎ 618、双11等
            - 热点活动
              - 官方活动
                - 小红书官方活动，可以按照小红书官方发起活动 [图:Bt4kbNC7Do3Oq5x1VnVcN9n5nAh]
              - 笔记灵感
                - 可以根据笔记灵感种的话题做内容，可以提高出爆款笔记的概率
        - 成倍增加内容价值
          - 爆款笔记核心要素：能否带来价值
          - 常见价值
            - 情绪价值 ⏎ 看完后舒适、快乐、激动
              - 励志
              - 慕强
              - 治愈
            - 内容价值
              - 实用内容 ⏎ 攻略、合集、教程
                - 一般以解决某个问题位目的，用通俗易懂的方式提供解决方案
              - 新知内容
                - 你分享的东西在别的地方看不到
                - 体现
                  - 主题稀缺
                    - eg：在英国将历史
